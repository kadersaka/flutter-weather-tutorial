## 🔧 **Architecture technique**

### **📁 Structure des fichiers**
```
lib/
├── models/           # Modèles de données météo
├── services/         # Service Open-Meteo API
├── providers/        # Gestion d'état avec Provider
├── screens/          # Écran principal
├── widgets/          # Widgets réutilisables
└── config/           # Configuration de l'application
```

### **🔄 Flux de données**
1. **Provider** gère l'état de l'application
2. **Service** fait les appels à Open-Meteo API
3. **Modèles** parsent les réponses JSON
4. **Widgets** affichent les données
5. **Gestion d'erreurs** robuste à chaque étape
